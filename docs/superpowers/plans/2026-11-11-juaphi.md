# จั่วผี (JuaPhi) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A multiplayer haunted-house card game ("draw and maybe die") played on phones from a shared link or a live room list, rendered with three.js.

**Architecture:** Pure rules module (`game/`) with injectable RNG, no I/O, returns events with public and secret parts. `server.js` owns rooms, sockets, the live room list and all timers (No! window, 15 s takeover), and sends each socket only what that player may see. The browser has no build step: an HTML overlay for lobby/buttons/text plus a three.js scene for the table, cards and effects.

**Tech Stack:** Node ≥18, `ws`, `three` (served from `node_modules` at `/vendor/`, loaded via import map), `node:test`, `linkedom` only if a DOM test needs it.

**Spec:** `docs/superpowers/specs/2026-11-11-ghost-card-game-design.md` (Thai). Read it before every task; rule wording there wins over paraphrase here.

## Global Constraints

- Original theme only. Never use the original game's name, card names, art or card text anywhere (code, UI, prompts, README).
- All player-facing text is Thai. Card names exactly as the spec table: ผี, ยันต์, ไม่!, ย่องหนี, สาปส่ง, สาปส่ง ×2, ส่องกระจก, ลมพัด, ขอของ, ผีน้อย (5 kinds; builder names them).
- Card ids: `ghost talisman nope sneak curse curse2 mirror wind beg imp1 imp2 imp3 imp4 imp5`.
- 2–8 seats per room including watchers; host can start with ≥2 players.
- Deal 1 talisman + 7 cards each from the deck without ghosts/talismans; then add ghosts = players − 1 and spare talismans; shuffle.
- Deck table (2–5 / 6–8): nope 5/10, sneak 4/8, curse 3/6, curse2 1/2, mirror 5/10, wind 4/8, beg 4/8, each imp 4/8, spare talisman 2/3. Constants at the top of `game/deck.js`.
- No! window 3000 ms, restarted by every No!, always opened even if nobody holds No!. Odd count cancels.
- Takeover after the waited-on player is offline 15000 ms (turn → draw, insert → random index, give → random card).
- Server never sends: other hands, deck order, insert index, mirror result (except to the peeker), identity of a begged/stolen card (except to the two players).
- Art: `public/cards/<id>.png` and `public/cards/back.png`, 5:7 (750×1050); missing file → text card. No code change to swap art.
- Respect `prefers-reduced-motion`: no shake, no flicker.
- Rooms in memory. Empty rooms removed.

## Review Focus

1. Duplicate/stale messages (double-tap, replayed card id, acting during a No! window or someone else's turn) must be rejected without changing state → tests in Task 2 and Task 3.
2. Secret leaks through *events*, not just views (a draw event naming the card, a steal event naming it, an insert event with the index) → test in Task 5.
3. The waited-on player disconnects in every waiting state (turn, insert, give) → game continues after 15 s → tests in Task 4 (rule) and Task 5 (timer).
4. A living player leaves mid-game while it is their turn, or while they owe a give → turn passes, ghost removed, game ends if one left → test in Task 4.
5. Thai text drawn to canvas before the web font has loaded renders in a fallback font forever → Task 7 waits on `document.fonts.load` before building card textures.

### Task 2: Turns, drawing, ghosts and the view

**Files:**
- Create: `game/game.js`, `game/view.js`
- Test: `test/game.test.js`, `test/view.test.js`

**Interfaces:**
- Consumes: `buildDeck`, `shuffle`, `makeRng`
- Produces:
  - `createGame(playerIds: string[], rng) -> Game` (current = playerIds[0], turnsLeft 1, cursed false)
  - `act(game, playerId, action, rng) -> Result`, this task handles `{ type: 'draw' }` and `{ type: 'insert', index: int }`
  - `endTurn(game)` internal: `turnsLeft -= 1`; at 0 → next alive player clockwise, `turnsLeft = 1`, `cursed = false`
  - `viewFor(game, playerId|null) -> { me?: { hand: Card[], alive, grudge }, players: [{ id, handCount, alive, grudge }], deckCount, discardTop: Card|null, current, turnsLeft, pending: <public form>, winner }`. Pending public form: window → `{kind, actor, kinds, target, nopeCount, }`; insert → `{kind, player}`; give → `{kind, from, to}`.

Draw rules: refuse if `pending` or not current or not alive. Draw top card. Non-ghost → to hand, event `{type:'draw', player, secret:{to:[player], card}}`, endTurn. Ghost with talisman → talisman to discard, event `{type:'ghost', player, saved:true}`, `pending = {kind:'insert', player}` (turn does not end until insert). Ghost without talisman → hand to discard, ghost removed from play, `alive=false`, `grudge=true`, event `{type:'ghost', player, saved:false}`; if one alive → `winner`, event `{type:'win', player}`; else endTurn passing the turn to the next alive player (remaining owed turns are discarded: next player gets `turnsLeft=1`). Insert: `0 ≤ index ≤ deck.length`, else error; splice ghost in, event `{type:'insert', player}` (no index), endTurn.

- [ ] **Step 1: Failing tests** (build states by hand with a fixed deck where needed):
  - non-current player draw → `ok:false`, state unchanged (deep-equal snapshot).
  - normal draw: hand +1, deck −1, turn passes to next alive.
  - ghost + talisman: talisman in discard, pending insert, turn not passed; `insert` index 2 puts ghost at `deck[2]`; turn passes; insert by another player → error; index −1 or > deck.length → error.
  - ghost without talisman: player dead, hand discarded, `grudge:true`; with 3 players → turn to the next alive; with 2 → `winner` set, further `act` → error.
  - dead players are skipped by endTurn.
  - `viewFor(g,'A')` contains A's hand, not B's; no `deck` array anywhere in the JSON (assert `!JSON.stringify(view).includes(deck[0].uid)` for a card not in A's hand); `viewFor(g,null)` has no `me`.
- [ ] **Step 2:** `npm test` → FAIL.
- [ ] **Step 3:** Implement `createGame`, `act` (draw, insert), `viewFor`.

### Task 3: Playing cards, No! window and effects

**Files:**
- Modify: `game/game.js`
- Test: `test/game.test.js`

**Interfaces:**
- Produces:
  - `act` actions: `{type:'play', uids:[...], target?, name?}`, `{type:'nope', uid}`, `{type:'give', uid}`
  - `resolvePending(game, rng) -> Result`: server calls this when the No! window timer fires. Applies the play if `nopes.length` is even.

Play validation: current player, alive, no pending, all uids in own hand and distinct. Valid sets: one of `sneak curse curse2 mirror wind beg`; two or three identical `impN`. `beg` and imp sets need `target` = another alive player with ≥1 card; triple needs `name` ∈ card kinds. `talisman`, `ghost`, `nope` cannot be played this way. Cards move to discard immediately; `pending = window`; event `{type:'play', player, kinds, target}`.
No!: any alive player (including actor) with that uid of kind `nope`, while pending is a window → card to discard, push nope, event `{type:'nope', player}`. Server restarts the timer on each.
Effects on resolve (event `{type:'resolve', cancelled, kinds}` always first):
- sneak: endTurn.
- curse/curse2: `bonus = 2|3`; next alive player's `turnsLeft = (cursed ? turnsLeft : 0) + bonus`, `cursed = true`, current = that player.
- mirror: event `{type:'mirror', player, secret:{to:[player], cards: deck.slice(0,3)}}`.
- wind: shuffle deck, event `{type:'wind'}`.
- beg: `pending = {kind:'give', from: target, to: actor}`; `give` by `from` moves that card, event `{type:'give', from, to, secret:{to:[from,to], card}}`. If target's hand is empty at resolve → no pending, event `{type:'give', from, to, empty:true}`.
- imp pair: random card from target to actor, event `{type:'steal', from, to, secret:{to:[from,to], card}}`.
- imp triple: if target holds `name`, move one; event `{type:'demand', from, to, name, got: bool}`.

- [ ] **Step 1: Failing tests:**
  - play `sneak` → window; `resolvePending` → turn passes, no card drawn.
  - curse stacking exactly as the spec example: A plays curse2 → B `turnsLeft 3`; B draws once (2 left); B plays curse → C `turnsLeft 4`. Also: normal turn curse → next player 2. Last cursed turn (B with 1 left, cursed) plays curse → C gets 3.
  - one No! cancels (card in discard, effect skipped); No! on No! (2) → effect applies.
  - actor can No! own play; non-holder No! → error; No! when no window → error.
  - during a window: `draw` and another `play` by current → error.
  - mirror: event secret lists the top 3 in order; public part has no cards.
  - beg: target gives a chosen card; give by anyone else → error; target with empty hand at resolve → no pending.
  - imp pair steals 1 card; mismatched imps (`imp1`+`imp2`) → error; triple with `name:'talisman'` takes the talisman when the target has one.
  - playing `talisman`, `ghost` or `nope` as a play → error; same uid twice in `uids` → error.
- [ ] **Step 2:** FAIL. **Step 3:** implement. **Step 4:** PASS.
- [ ] **Step 5:** Commit `feat: action cards, No! window and imp sets`.

### Task 4: Grudge, leaving and takeover

**Files:**
- Modify: `game/game.js`
- Test: `test/game.test.js`

**Interfaces:**
- Produces:
  - `act` action `{type:'grudge', target}`: actor dead with `grudge:true`, no `pending` of any kind, target alive with ≥1 card → random card from target's hand to discard, `grudge=false`, event `{type:'grudge', from, to, card}` (card is public per spec).
  - `removePlayer(game, playerId, rng) -> Event[]`: hand to discard; if alive: mark dead (no grudge), remove one ghost from the deck if any; clear pending that involves them (window by them → resolve as cancelled; give from them → give a random card if any, else drop; insert by them → insert at random index); if it was their turn → pass to next alive with `turnsLeft 1`; check winner.
