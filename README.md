# จั่วผี

เกมการ์ดบ้านผีสิงเล่นกับเพื่อนบนเว็บ ทุกคนผลัดกันจั่วการ์ด ใครจั่วได้ **ผี** แล้วไม่มี **ยันต์** ตกรอบ คนสุดท้ายที่รอดชนะ
เล่นจากมือถือคนละเครื่อง ส่วนการคุยกันไปคุยใน Discord หน้าเว็บเป็นกระดาน 2D แบบ HTML ล้วน

- ผู้เล่น 2-8 คน (นับรวมคนที่เข้ามาดู)
- ผู้ชนะในแต่ละรอบได้ 1 แต้ม ใครชนะครบ 3 รอบก่อนเป็นผู้ชนะชุด คะแนนอยู่กับห้องและต่อกลับมาได้ หัวห้องกดเล่นรอบถัดไปได้โดยเก็บคะแนนเดิม หรือเริ่มชุดใหม่หลังมีผู้ชนะเพื่อล้างคะแนนเป็น 0
- ไม่มีฐานข้อมูล ห้องอยู่ในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วห้องหาย
- กติกาอยู่ใน `game/` (ทดสอบด้วย `npm test`) ส่วนห้องกับ WebSocket อยู่ใน `server.js` หน้าเว็บอยู่ใน `public/`

## ลองบนเครื่องตัวเอง

```bash
npm install
```

```bash
npm start
```

เปิด http://localhost:3000 แท็บธรรมดาในเบราว์เซอร์เดียวกันใช้ตัวตนเดียวกัน ถ้าจะลองหลายคนให้เปิดแบบไม่ระบุตัวตน
หรือให้บอตเข้ามาเล่นด้วย (ใส่รหัสห้องที่เห็นบนหน้าห้องรอ):

```bash
node tools/bot.js ABCD ผีบอต 3000
```

## วิธีเล่น

1. ใส่ชื่อ แล้วกด **สร้างห้องใหม่** หรือแตะห้องในรายการ **ห้องที่เปิดอยู่** หรือเปิดลิงก์เชิญที่เพื่อนส่งมา
   ห้องที่กำลังเล่นอยู่ แตะเข้าไปดูได้ แล้วได้เล่นในเกมถัดไป
2. หัวห้องกด **เริ่มเกม** ทุกคนได้ยันต์ 1 ใบกับการ์ดอีก 7 ใบ ในกองมีผีน้อยกว่าจำนวนคนอยู่ 1 ใบ
3. ในตาของคุณ แตะการ์ดในมือเพื่อเลือก แล้วกดปุ่มเล่น จะเล่นกี่ใบก็ได้ แล้วกด **จั่ว** เพื่อจบตา
4. จั่วได้ผีแต่มียันต์ ระบบใช้ยันต์ให้เอง แล้วคุณเลือกว่าจะแอบเสียบผีกลับเข้ากองตรงไหน ถ้าไม่มียันต์ก็ตกรอบ
   ถ้าหัวห้องเปิด **ผีร้าย** ไว้ในห้องรอ ผีใบหนึ่งจะเป็นผีร้าย จั่วได้ต้องใช้ยันต์ทั้งหมดในมือปัดเป่า (รอดแล้วผีร้ายกลับเข้ากองเหมือนผีปกติ)
5. คนที่ตกรอบกลายเป็นวิญญาณ ใช้ **อาฆาต** ได้ 1 ครั้ง: เลือกคนที่ยังรอด แล้วระบบสุ่มทิ้งการ์ดในมือเขา 1 ใบ

| การ์ด | ผล |
|---|---|
| ไม่! | ยกเลิกการ์ดที่คนอื่นเพิ่งเล่น (มีเวลา 2.5 วินาที ใช้ "ไม่!" ซ้อน "ไม่!" ได้) |
| ย่องหนี | จบตาโดยไม่ต้องจั่ว |
| สาปส่ง / สาปส่ง ×2 | จบตาไม่ต้องจั่ว คนถัดไปเล่น 2 / 3 ตา ถ้าโดนสาปอยู่แล้วสาปต่อ ตาที่เหลือทบไปด้วย |
| ส่องกระจก | แอบดูการ์ด 3 ใบบนกอง |
| ลมพัด | สับกอง |
| ขอของ | เลือกเพื่อน ให้เขาเลือกการ์ดยกให้คุณ 1 ใบ |
| ผีน้อย (กุมารทอง กระสือ กระหัง ปอบ ตานี) | คู่เดียวกัน = ขโมยการ์ดเพื่อนแบบสุ่ม · สามใบ = ทวงการ์ดที่ระบุชื่อ |

ตอนต้องเลือกเพื่อน แตะป้ายชื่อบนโต๊ะหรือกดชื่อในกล่องเลือกก็ได้
ถ้าคนที่เกมรออยู่หลุดเกิน 15 วินาที ระบบจะเล่นแทน (จั่ว เสียบผี หรือให้การ์ด) เปิดลิงก์เดิมจากเครื่องเดิมก็กลับมาที่เดิมพร้อมการ์ดในมือ

## ปรับกติกา

- ขนาดกอง: `DECK_AFTER_DEAL` กับ `DECK_GROW` ต้นไฟล์ `game/deck.js` (กองจั่วหลังแจก 30 ใบใน 2-4 คน เกินนั้นเพิ่มคนละ 5 ใบ นับผีกับยันต์สำรองด้วย)
- สัดส่วนการ์ดแต่ละแบบ: `DECK_TABLE` / `EXTRA_TABLE` (ระบบย่อหรือขยายตามสัดส่วนให้ได้ขนาดกองข้างบน) กับ `SPARE_TALISMANS`
  แก้ตรงนี้แล้วแก้สำเนาใน `public/cards.js` ให้ตรงกันด้วย (`npm test` เช็กให้)
- เวลากด "ไม่!" กับเวลารอคนหลุด: `NOPE_MS`, `GRACE_MS` ต้นไฟล์ `server.js` (ถ้าแก้ `NOPE_MS` ให้แก้ค่าเดียวกันใน `public/ui.js` ด้วย ใช้วาดแถบนับเวลา)
- ชื่อและคำอธิบายการ์ด: `CARD_INFO` ใน `public/cards.js`

แก้แล้วรัน `npm test`

## ภาพการ์ด

ภาพต้นฉบับ (PNG แนวตั้ง 5:7 เช่น 750×1050) วางไว้ที่ `art/<id>.png` และหลังการ์ดที่ `art/back.png`
แล้วรันคำสั่งนี้ (ต้องมี ffmpeg) เพื่อย่อเป็น WebP 500×700 ลง `public/cards/` ซึ่งเป็นไฟล์ที่หน้าเว็บโหลดจริง
(ต้นฉบับรวมประมาณ 27 MB ย่อแล้วเหลือไม่ถึง 1 MB โหลดในมือถือเร็วกว่ากันมาก)

```bash
npm run art
```

โฟลเดอร์ `art/` ไม่ได้ขึ้น git (ไฟล์ใหญ่) ให้เก็บสำรองต้นฉบับไว้เอง ส่วน `public/cards/*.webp` ขึ้น git
ถ้าวางแค่ PNG ไว้ใน `public/cards/` ตรงๆ เกมก็ใช้ได้ แต่ไฟล์จะใหญ่ ถ้าไม่มีภาพเลย เกมวาดการ์ดสีพื้นพร้อมชื่อแทน
ชื่อการ์ดกับคำอธิบาย เกมเขียนทับให้ที่แถบบนและล่างเอง ไม่ต้องอยู่ในภาพ
prompt สำหรับให้ Codex สร้างภาพอยู่ใน `docs/card-art-prompts.md`

id ของการ์ด: `ghost evil talisman nope sneak curse curse2 mirror wind beg imp1 imp2 imp3 imp4 imp5`

## ขึ้นเซิร์ฟเวอร์

อยู่บนเครื่อง 129.121.129.56 (ย้ายมาจาก Vultr 207.148.66.224 เมื่อ 2026-11-15) ไฟล์ทั้งหมดอยู่ใน `tools/deploy/`
ตั้งเครื่องใหม่ทั้งเครื่อง (Node, swap, firewall, cloudflared) ด้วย `tools/deploy/setup-machine.sh` ครั้งเดียว ทุกเกมบนเครื่องใช้ร่วมกัน

| | |
|---|---|
| พอร์ต (ฟังที่ 127.0.0.1) | 3030 |
| user ที่รัน | `juaphi` |
| โค้ด | `/opt/juaphi` (root เป็นเจ้าของ เกมอ่านได้อย่างเดียว) |
| repo บนเซิร์ฟเวอร์ | `/opt/juaphi.git` (remote ชื่อ `server`) |
| โดเมน | juaphi.laxezice.win |

เกมไม่เก็บข้อมูลลงดิสก์ ห้องอยู่ในหน่วยความจำ ทุกครั้งที่อัปเดตหรือรีสตาร์ต ห้องที่เปิดอยู่จะปิด

### อัปเดตเกม

```bash
powershell -ExecutionPolicy Bypass -File tools\deploy\deploy.ps1
```

สคริปต์เช็กก่อนว่ามีคนเล่นอยู่ไหม ถ้ามีจะหยุด (สั่งซ้ำพร้อม `-Force` ถ้าจะอัปเดตทั้งที่มีคนเล่น)
แล้ว push `main` ไปที่เซิร์ฟเวอร์ และรัน `update.sh` (checkout, `npm ci`, ติดตั้ง service, รีสตาร์ต, เช็ก `/healthz`)
ย้อนกลับไปรุ่นก่อนด้วย `-Ref <commit>`

ดูว่ามีใครเล่นอยู่ (ทุกเกมบนเครื่องที่รองรับ):

```bash
powershell -ExecutionPolicy Bypass -File tools\deploy\rooms.ps1
```

บนเซิร์ฟเวอร์: `systemctl status juaphi`, `journalctl -u juaphi -f`, `systemctl restart juaphi`

### ขึ้นครั้งแรก / ย้ายเครื่อง

1. บนเซิร์ฟเวอร์: คัดลอก `tools/deploy/setup-server.sh` ขึ้นไปแล้วรัน `bash setup-server.sh` (สร้าง user, repo เปล่า และโฟลเดอร์โค้ด)
2. ในเครื่องนี้: `git remote add server root@<IP>:/opt/juaphi.git` แล้ว ssh เข้าเครื่องหนึ่งครั้งให้รู้จัก host key
3. รัน `deploy.ps1` (ย้ายเครื่องใช้ `-Server root@<IP ใหม่>`)
4. เพิ่มใน `/etc/cloudflared/config.yml` เหนือบรรทัด `- service: http_status:404`

   ```yaml
   - hostname: juaphi.laxezice.win
     service: http://127.0.0.1:3030
   ```

   แล้ว `cloudflared tunnel route dns <tunnel> juaphi.laxezice.win` หนึ่งครั้ง และ `systemctl restart cloudflared`
   (ทุกเกมบนเครื่องจะหลุดการเชื่อมต่อแป๊บหนึ่ง)

เครื่อง 129.121.129.56 ใช้ tunnel ของตัวเองชื่อ `games` (Vanguard ยังอยู่เครื่อง Vultr กับ tunnel `vanguard`)
การสร้าง tunnel กับย้าย DNS เจ้าของบัญชี Cloudflare ทำเอง จากเครื่องนี้ที่ login cloudflared ไว้แล้ว:
tunnel `games` (ID `0830ec10-de98-41bc-b424-ab4d73f328bd`) รันบนเครื่องใหม่เป็น service `cloudflared` config อยู่ที่ `/etc/cloudflared/config.yml`
ย้ายโดเมนมาเครื่องใหม่ (ใช้ ID และ config ว่าง เพราะ `~/.cloudflared/config.yml` ในเครื่องนี้ผูกกับ tunnel `vanguard`
ถ้าไม่ข้าม cloudflared จะใช้ tunnel นั้นแทนชื่อที่พิมพ์):
`cloudflared --config <ไฟล์ว่าง> tunnel route dns --overwrite-dns 0830ec10-de98-41bc-b424-ab4d73f328bd <host>`
ย้อนกลับไปเครื่องเก่าด้วยคำสั่งเดียวกันแต่ใช้ ID ของ `vanguard` (`5eb319c2-3578-43a4-bce7-d6f68bb8fd49`)
